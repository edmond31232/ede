# ede

משחק דפדפן קליל: "דגי-פרצופים" 🐠

## מה יש כאן?
- שני דגים שוחים במים ומנסים לתפוס אוכל נופל.
- אפשר להעלות תמונת פנים לכל דג (Upload) כדי לשחק עם "דגים-עם-פרצוף".
- משחק של 60 שניות עם ניקוד לשני שחקנים.

## איך מריצים?
פשוט פותחים את `index.html` בדפדפן.

אופציה עם שרת מקומי:

```bash
python3 -m http.server 8000
```

ואז להיכנס ל:

`http://localhost:8000`

## מקשים
- שחקן שמאל: `A` / `D`
- שחקן ימין: `←` / `→`
