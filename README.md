# ede

"דגי־פרצופים" הוא משחק דפדפן קצר וכיפי:
- מעלים פרצוף לכל דג (לא חובה, יש אימוג'י ברירת מחדל).
- הדגים שוחים ומנסים לתפוס את האוכל שאתם זורקים למים.
- המשחק נמשך 75 שניות ומחשב ניקוד לכל צד.

## הרצה מקומית
```bash
python3 -m http.server 8000
```

אחר כך פותחים בדפדפן:
`http://localhost:8000`

## שליטה
- דג שמאל: `A` / `D`
- דג ימין: `←` / `→`
- זריקת אוכל: כפתור "זרוק אוכל", מקש `Space`, או קליק על הקנבס
- במובייל/עכבר: גרירה בכל חצי מסך מזיזה את הדג באותו צד
